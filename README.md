# Home Assistant InfluxDB v1 App Repository

Community Home Assistant OS App repository containing an InfluxDB 1.8.10 app for legacy InfluxDB 1.x consumers such as BESS Manager.

## Repository

Add this URL to Home Assistant's App repository list:

https://github.com/VillaSkevik/homeassistant-addon-influxdb-v1

## Included app

- `influxdb/` — InfluxDB 1.8.10
- Raspberry Pi 4 / `aarch64` supported
- `armv7` retained for compatible 32-bit systems
- HTTP API on TCP 8086
- Flux enabled

This repository is independently maintained and is not affiliated with Home Assistant or InfluxData.
